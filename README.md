# Telegram_API
Простая связка плагин + апи на удаленном сервере для работы ботов.

# Работа с API-Telegram

__Выполнить акцивация виртуального окружения и установить пакеты:__

```pip install fastapi uvicorn```

__После чего запустить основной скрипт:__

```python3 main.py``` _(для Linux)_

```python main.py``` _(для Windows)_
